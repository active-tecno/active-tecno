# اكتف اوردر (Active Tecno)

منصة متاجر إلكترونية عربية كاملة للسوق المصري — قوالب جاهزة، دفع عند الاستلام (COD)، تحليلات، لوحة تحكم تاجر، ولوحة إدارة منصة.

**بدون أي مكتبات خارجية.** Node.js + SQLite فقط (وحدة `node:sqlite` المدمجة).

## التشغيل (أمر واحد)

```bash
node server.js
```

ثم افتح http://localhost:3000

> يتطلب Node.js 22.5 أو أحدث. قاعدة البيانات SQLite تُنشأ وتُملأ ببيانات تجريبية تلقائياً عند أول تشغيل.

## الحسابات التجريبية

| الحساب | البريد | كلمة المرور |
|---|---|---|
| تاجر (متجر نورا) | `demo@activetecno.software` | `demo1234` |
| إدارة المنصة | `admin@activetecno.software` | `admin1234` |

## الخريطة

| المسار | الوصف |
|---|---|
| `/` | الصفحة التسويقية |
| `/register` · `/login` | تسجيل تاجر جديد / دخول |
| `/app` | لوحة تحكم التاجر (منتجات، طلبات، تحليلات، كوبونات، شحن، تخصيص…) |
| `/s/:slug` | واجهة المتجر (مثال: `/s/noura`) |
| `/s/:slug/checkout` | إتمام الطلب — صفحة واحدة، دفع عند الاستلام |
| `/admin` | لوحة إدارة المنصة (تجار، تفعيلات، إحصائيات) |

## بنية المشروع

```
server.js            خادم HTTP + التوجيه + كل نقاط الـ API
db.js                اتصال SQLite + نظام المايجراشنز
seed.js              القوالب + البيانات التجريبية (تُنفذ مرة واحدة)
views.js             الصفحات المولدة من الخادم (الهبوط، الدخول، واجهة المتجر)
public/css/*         تصميم الهبوط / المتجر / اللوحة
public/js/store.js   سلة المتجر وتتبع الأحداث وإتمام الطلب
public/js/dashboard.js  لوحة تحكم التاجر (SPA)
public/js/admin.js      لوحة الإدارة (SPA)
data/                قاعدة البيانات والصور المرفوعة (تُنشأ تلقائياً)
```

## ما هو حقيقي وما هو محاكى (mock)

- **حقيقي:** قاعدة البيانات، الحسابات والجلسات، المنتجات والصور والمخزون، الطلبات وحالاتها، الكوبونات، مناطق الشحن، الحظر، السلات المتروكة، التحليلات والفانل، التصدير CSV، تفعيل النشر بمراجعة يدوية.
- **محاكى:** التحويل المالي (InstaPay / Vodafone Cash) — التاجر يُدخل رقم مرجع والإدارة تقبل يدوياً من لوحة الإدارة. رسائل واتساب — تُفتح روابط `wa.me` جاهزة الرسالة (لا يوجد إرسال تلقائي فعلي). البيكسلات تُحفظ إعداداتها فقط دون إرسال أحداث خارجية.
